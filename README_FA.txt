ALI SARAN PLANNER — PWA

این نسخه PWA است و برای نصب روی گوشی طراحی شده.

روش نصب:
1) فایل‌های این پروژه باید روی یک HTTPS hosting قرار بگیرند.
2) لینک سایت را با Chrome گوشی باز کن.
3) از منوی سه‌نقطه Chrome گزینه Install app یا Add to Home screen را بزن.
4) آیکن Ali Saran Planner روی صفحه اصلی ظاهر می‌شود.

نکته:
باز کردن index.html به صورت مستقیم از فایل‌های گوشی، معمولاً Service Worker را فعال نمی‌کند؛ برای نصب واقعی PWA باید روی HTTPS اجرا شود.

برای انتشار رایگان می‌توانی پروژه را روی GitHub Pages / Netlify / Vercel قرار دهی.
